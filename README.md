# 🚀 Dev Stack

Dev Stack is a modern web application that helps developers explore different technologies and build their own development stack. Users can browse technologies by category and add their preferred technologies to their stack.

## 🔗 Live Preview

live website link : [https://devstack.mehedihasanbd.com/](https://devstack.mehedihasanbd.com/)

---

## 📖 Project Description

Dev Stack is designed to make it easy for developers to discover popular frontend, backend, database, programming language, and DevOps technologies. Users can explore different technology cards, view basic information, and create their own customized technology stack.

---

## 🛠️ Technologies Used

- React.js
- JavaScript
- Tailwind CSS
- HTML5

- React Hooks
- JSON Data

---

## ✨ Features

### 1. Explore Technologies
Users can browse different technologies such as React, Vue.js, Next.js, Node.js, JavaScript, TypeScript, Docker, PostgreSQL, and more.

### 2. Build Your Own Stack
Users can add technologies to their personal development stack and see their selected items.

### 3. Responsive User Interface
The website has a clean and responsive design that works across different screen sizes.

# ⚛️ React Questions

## i. What is JSX, and why is it used in React?

JSX allows us to write HTML-like code inside JavaScript. It is used to create React UI easily.

---

## ii. What is the difference between props and state?

Props are passed from parent to child components. State stores and manages changing data inside a component.

---

## iii. What does the `useState` hook do, and where did you use it in this project?

`useState` is used to manage changing data. I used it to manage the selected technologies in the stack.

---

## iv. What does the `useEffect` hook do, and why did you need it to load the JSON data?

`useEffect` runs side effects in React. I used it to load the JSON data when the component loads.

---
## v. Why does every item in a `.map()` list need a unique `key` prop?

A unique `key` helps React identify and update each list item efficiently.

---

## vi. What is conditional rendering? Show one place you used it.

Conditional rendering means showing different UI based on a condition. For example, showing **"Your stack is empty"** when no technology is selected.

---
### vii. How do you pass data from a parent component to a child component, and how does a child send something back to the parent?
A parent passes data to a child using **props**. A child sends data back by calling a **function passed from the parent through props**.
